# Contributing

Open an issue with app/Kavita/Android versions, reproduction steps, expected and actual results, and reader type. Review diagnostics before attaching them. Do not include credentials, invitation links or book libraries.

Work on a branch and submit a focused pull request. Run the applicable checks in [BUILD](docs/BUILD.md), report results and limitations, and preserve the contracts in [ARCHITECTURE](docs/ARCHITECTURE.md). Never test progress writes against production or use test devices with personal data.

Maintain **both Spanish and English UI resources**. Public documentation, issues and code explanations should be in English; Spanish bug reports are welcome. See [LOCALIZATION](docs/LOCALIZATION.md). Do not translate protocol keys, serialized state markers, user notes or server content.

Contributions are distributed under GPL-3.0. Do not add books, images or SDKs without a compatible licence.
