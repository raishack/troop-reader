# Contribuir

Abre una issue con versión de app/Kavita/Android, pasos, resultado esperado/real y tipo de lector. No adjuntes credenciales, enlaces de invitación, bibliotecas ni diagnósticos sin revisarlos.

Trabaja en una rama y envía una PR acotada. Ejecuta las comprobaciones de BUILD apropiadas; describe pruebas y límites. Conserva los contratos de ARCHITECTURE. No usar producción para pruebas que escriben progreso ni emuladores con datos reales.

Mantén interfaz y documentación en español. Las contribuciones se distribuyen bajo GPL-3.0, igual que el proyecto. No incorporar obras, imágenes o SDK sin licencia compatible.
