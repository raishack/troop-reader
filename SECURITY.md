# Seguridad

No publiques vulnerabilidades con datos de cuentas. Usa el reporte privado de seguridad de GitHub si está disponible. No adjuntes tokens, contraseñas, bases de datos, copias de configuración, enlaces de invitación, claves de firma ni contenido de libros.

El cliente usa HTTPS verificado, sesiones privadas, HTML offline restringido y verificación de firma/hash de actualizaciones. Estas medidas no sustituyen una auditoría independiente. El parche de Kavita es específico de versión y debe mantener las peticiones anónimas denegadas.

Las pruebas y los valores de credenciales del código son sintéticos. Las claves de firma y los datos operativos no forman parte de este repositorio.
